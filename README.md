## Sobre o projeto

**Forest Whispers** foi meu **primeiro projeto desenvolvido utilizando a Godot Engine**.

O projeto foi criado principalmente como uma forma de **estudar, aprender e experimentar o desenvolvimento de jogos em 3D**, especialmente dentro da Godot.

Durante o desenvolvimento, utilizei o projeto para aprender e colocar em prática conceitos como:

- Desenvolvimento de jogos 3D
- Movimentação em primeira pessoa
- Controle de câmera
- Sistema de corrida
- Stamina
- Lanterna
- Interação com objetos
- Áudio 3D
- Efeitos sonoros
- Iluminação
- Ambientes de terror
- Sistemas de interação
- Atmosfera e ambientação
- Efeitos visuais inspirados em VHS

Por esse motivo, **Forest Whispers não foi desenvolvido como um produto comercial**.

O objetivo principal era aprender a utilizar a Godot e entender como diferentes sistemas de um jogo poderiam ser desenvolvidos e integrados.

---

## Sobre o jogo

**Forest Whispers** é um projeto experimental de terror em primeira pessoa ambientado em uma floresta.

A proposta do projeto era criar uma experiência de exploração e suspense, utilizando iluminação escura, sons ambientes, efeitos visuais e uma estética inspirada em gravações antigas e VHS.

O projeto foi desenvolvido durante meu processo inicial de aprendizado na Godot.
